1 · Conventions & Common Flow

All commands run from RTL/vortex/dv/sim after source ~/cshrc (Xcelium 25.03). Kernels are built once with make -C ../sw (GNU RV32 toolchain at /home/user1/vortex/riscv32-gnu-toolchain).

Every UVM run follows the same skeleton (see the Verification Plan): load +KERNEL hex at 0x8000_0000 → 17 DCR boot writes → start pulse → serve memory until busy is low 100 cycles (2M-cycle watchdog) → cache-flush DCR read → scoreboard checks. Baseline pass criteria for every test:

  • UVM_ERROR : 0; no watchdog timeout;
  • exit word @0x8348 == 0 (non-zero = failing self-check id);
  • done magic 0x600DC0DE @0x8350; live exit-write seen; n_rd > 0.

Check-layer tags used below: Layer A software, Layer B UVM scenario, Hybrid cross-check.

2 · Layer A — asm Micro-Tests

SW-ASM-01 nop — hand-assembled boot proof Layer A

Sourcedv/sw/tests/asm/nop.hex — 8 hand-assembled instructions, no toolchain needed (also the bring-up kernel used before the toolchain existed)
IntentAbsolute-minimum kernel: write exit code 0 → 0x8348, done magic → 0x8350, wsync, tmc x0. Proves fetch, decode, store, and the retire path.
ExpectedBaseline criteria only; ~3 memory reads, 1 write line observed.
Buildnone (checked-in hex)
Runmake vx_smoke · make sim TESTNAME=vx_base_test KERNEL=asm/nop

SW-ASM-02 self_check — RV32IM instruction sanity Layer A

Sourcedv/sw/tests/asm/self_check.S
Intent12 riscv-tests-style checks with known operands/results: add, sub, and/or/xor, sll/srl/sra, slt/sltu, mul, divu, remu, and load variants (lw, lhu, lb sign-extension). Each check that fails puts its check id in a0 — the exit code pinpoints the broken instruction.
Expecteda0 = 0 (all 12 pass) → exit 0.
Buildmake -C ../sw → self_check.{elf,bin,hex,dis}
Runmake sim TESTNAME=vx_asm_test KERNEL=asm/self_check · make cosim KERNEL=asm/self_check

SW-ASM-03 divergence — warp/thread fabric Layer A

Sourcedv/sw/tests/asm/divergence.S
IntentThe only test that leaves single-hart mode. Phase 1: tmc -1 activates all 4 threads; each writes 0xA0+tid (CSR 0xCC0) to its slot at 0x8003_0000; tmc 1 narrows back; thread 0 verifies all 4 slots. Phase 2: wspawn NUM_WARPS (CSR 0xFC1) launches warps 1–3 at a spawn entry; each writes 0xB0+wid (CSR 0xCC1) to slots at 0x8003_0100, then wsync/tmc x0; warp 0 polls the slots and verifies.
ExpectedAll per-thread and per-warp slots correct → exit 0. Exercises tmc, wspawn, wsync, thread/warp-id CSRs, and inter-warp memory visibility.
Buildmake -C ../sw
Runmake sim TESTNAME=vx_base_test KERNEL=asm/divergence · make cosim KERNEL=asm/divergence
Historical bug this test caught in itself: NUM_WARPS is CSR 0xFC1; 0xFC2 is NUM_CORES. Reading 0xFC2 spawned 1 warp and hung the poll loop.

3 · Layer A — C Kernels

All C kernels: -march=rv32imf_zicsr -mabi=ilp32 -O2, bare-metal (crt0.S + link.ld), self-checking (return 0 = pass, else failing index), and publish results to OUT_ADDR = 0x8002_0000 for the independent output-region checks.

SW-C-01 vecadd — vector add (flagship) Layer A

Sourcedv/sw/tests/c/vecadd.c (+ vecadd_expected.py golden generator)
IntentN=16: a[i]=4i, b[i]=6i+3 → c[i]=10i+3 written to OUT_ADDR; kernel self-verifies then exits. The canonical GPGPU hello-world with three independent references.
Expectedexit 0; 16 words at 0x8002_0000 match vecadd.expected.hex (layer ②), the DPI-C ref (layer ③), and simx (layer ④).
Buildmake -C ../sw (also regenerates the .expected.hex)

SW-C-02 memcpy_stride — memory movement patterns Layer A

Sourcedv/sw/tests/c/memcpy_stride.c
Intentsrc[i]=5i+1 (36 words); three copies into distinct OUT_ADDR regions: forward word copy, backward copy, stride-4 gather. Stresses LSU addressing, dcache line reuse/eviction, and the banked write path (144 output bytes span multiple 64-byte lines on both banks).
Expectedexit 0; 36 output words match the DPI-C golden (layer ③) and simx.
Runmake sim TESTNAME=vx_base_test KERNEL=c/memcpy_stride HYBRID=1 · make cosim KERNEL=c/memcpy_stride

SW-C-03 ctrl_flow — branches, loops, recursion-shapes Layer A

Sourcedv/sw/tests/c/ctrl_flow.c
IntentFour algorithms with data-dependent control flow: fib(12)=144 (loop), collatz(27)=111 steps (while + parity branches), gcd(1071,462)=21 (modulo loop), popcount(0xF00F5A5A)=16 (bit loop). Results to OUT_ADDR.
Expectedexit 0; 4 output words match the DPI-C golden (layer ③) and simx.
Runmake sim TESTNAME=vx_base_test KERNEL=c/ctrl_flow HYBRID=1 · make cosim KERNEL=c/ctrl_flow

SW-C-04 fp_ops — FPNEW datapath Layer A

Sourcedv/sw/tests/c/fp_ops.c
IntentF-extension through the pure-RTL FPNEW unit: float add, mul, fma-shaped (a*b+c), div over arrays of exactly-representable values (no rounding ambiguity), plus int↔float conversions and FP compares. N=8.
Expectedexit 0 (bit-exact self-check); simx agreement (layer ④).
Runmake sim TESTNAME=vx_base_test KERNEL=c/fp_ops · make cosim KERNEL=c/fp_ops

5 · Hybrid Combinations

HYB-01 DPI-C reference check Hybrid

PiecesUVM scoreboard (SV) + dv/sw/ref/vx_ref.c compiled into the simulation by xrun (HYBRID=1), exporting vx_ref_num_words()/vx_ref_word().
ObjectiveC↔SV↔UVM interplay: the host recomputes the kernel's output with the same algorithm; the scoreboard compares word-by-word at 0x8002_0000. Golden models exist for vecadd (16 w), memcpy_stride (36 w), ctrl_flow (4 w); other +REF names are info-skipped.
Runmake sim TESTNAME=vx_base_test KERNEL=c/vecadd HYBRID=1 → expect RESULT: DPI-C reference check PASSED

HYB-02 simx co-simulation Hybrid

PiecesSame ELF replayed on the simx golden simulator (/home/user1/vortex/.../build/sim/simx/simx); its process rc = exit word low byte.
ObjectiveIndependent semantic reference — validates program and environment assumptions (boot DCRs, memory interleave) against upstream's own model.
Runmake cosim KERNEL=<elf kernel> → expect COSIM: [OK]. Applicable to all 6 ELF kernels (not the checked-in nop.hex).
