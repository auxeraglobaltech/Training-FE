Building Blocks

sequence seq_name; // Boolean events over time a ##2 b; endsequence property prop_name; // Clock + implication live here @(posedge clk) a |-> ##2 b; endproperty lbl: assert property(prop_name) else $error("msg");
LayerRole
sequenceNamed Boolean timeline
propertyRule + clock + implication
assert propertyActivates the checker

Timing — ## Operator

SyntaxMeaning
a ##1 bb exactly 1 cycle after a
a ##2 bb exactly 2 cycles after a
a ##[1:4] bb within 1–4 cycles after a
a ##[0:4] bb same cycle or within 4
a ##[1:$] bb eventually (unbounded)
a ##0 ba and b same clock edge
⚑ Clock best practice: define the clock in property, not inside sequence — enables sequence reuse across clock domains.

Implication Operators

OpNameConsequent starts
|->OverlappedSame cycle as antecedent
|=>Non-overlappedNext cycle after antecedent
// Same cycle check a |-> b // Next cycle check a |=> b // Fixed delay on consequent a |-> ##2 b // Timing window a |-> ##[1:4] b // Sequence antecedent seq1 |-> seq2

Repetition Operators

SyntaxTypeDescription
b[*3]Consecutiveb high for exactly 3 back-to-back cycles
b[*2:4]Consecutive rangeb high 2 to 4 consecutive cycles
b[->3]Go-tob high 3 times (not necessarily consecutive); last match immediately before next element
b[=3]Non-consecb high 3 times; last match may be followed by any cycles before next element
b[*0:$]Unboundedb high zero or more cycles (used in variable-delay pattern)
// Burst of 3 → done high burst_start |-> ##1 data[*3] ##1 done // ack fires 3 times then done high start |-> ##1 ack[->3] ##1 done

Immediate Assertions

// Basic — $error by default on fail assert(expr); // With pass/fail actions assert(expr) $display("pass"); else $error("fail"); // With label lbl: assert(a && b) else $fatal("msg");

Built-in Methods & System Functions

FunctionReturns true when…
$rose(sig)LSB of sig changed to 1
$fell(sig)LSB of sig changed to 0
$stable(sig)sig value did not change
$past(sig,N)Value of sig N cycles ago
$past(s,N,gate)$past with clock gating signal
$onehot(expr)Exactly one bit is high
$onehot0(expr)Zero or one bit is high
$isunknown(expr)Any bit is X or Z
$countones(expr)Count of high bits (use in condition)
// Structural monitors — always-on assert property(@(posedge clk) $onehot(state)); assert property(@(posedge clk) !$isunknown(bus)); assert property(@(posedge clk) $rose(en) |-> ##1 !irq);

Advanced Constructs

// disable iff — reset-safe assertions property p; @(posedge clk) disable iff (reset) req |-> ##[1:4] ack; endproperty // .ended — synchronise sequence endpoints seq1.ended |-> ##2 seq2.ended; // Variable delay workaround sequence delay_seq(v); int d; (1,d=v) ##0 first_match((1,d=d-1)[*0:$] ##0 d<=0); endsequence req |-> delay_seq(cfg_lat) |-> ack;

Common Verification Patterns

Handshake / REQ-ACK
property p_req_ack; @(posedge clk) disable iff (rst) req |-> ##[1:4] ack; endproperty
AXI-style valid/ready
property p_valid_stable; @(posedge clk) (valid && !ready) |-> $stable(data) && valid; endproperty
One-hot FSM guard
assert property( @(posedge clk) $onehot(state) );
Post-reset clean bus
property p_no_x; @(posedge clk) $rose(rstn) |-> ##1 (!$isunknown(data))[*2]; endproperty
Data burst (N beats)
property p_burst; @(posedge clk) disable iff (rst) start |-> ##1 data_valid[*4] ##1 done; endproperty
Cause-before-effect ($past)
property p_causality; @(posedge clk) ack |-> ($past(req, 2) == 1); endproperty
