# SRAM FIFO AXI Interface Design

## Overview

This project implements a data buffering and transfer architecture that accepts variable-width transition data, packs it into fixed 64-bit words, stores the packed data in a FIFO buffer, and transfers the FIFO contents to an AXI-based memory.

The design consists of the following major modules:

* Transition Packer
* FIFO Buffer
* FIFO AXI Wrapper
* AXI RAM
* Top-Level Integration

## Architecture

```text
                    Variable-Width Transition Data
                              |
                              v
                  +-----------------------+
                  |   Transition Packer   |
                  |                       |
                  | Variable Data ->      |
                  | 64-bit FIFO Words     |
                  +----------+------------+
                             |
                             v
                  +-----------------------+
                  |      FIFO Buffer      |
                  |                       |
                  |     512 x 64-bit      |
                  +----------+------------+
                             |
                             v
                  +-----------------------+
                  |   FIFO AXI Wrapper    |
                  |                       |
                  | 8 x 64-bit ->         |
                  | 1 x 512-bit AXI Data  |
                  +----------+------------+
                             |
                             v
                  +-----------------------+
                  |        AXI RAM        |
                  |                       |
                  |   AXI Memory Model    |
                  +-----------------------+
```

## Module Description

### 1. Transition Packer

**File:** `rtl/transition_packer.v`

The Transition Packer accepts variable-width transition data and packs it into fixed 64-bit words before writing them into the FIFO.

Main functions:

* Accepts variable-width transition data.
* Tracks the number of valid bits in the packing buffer.
* Packs multiple transitions into a single 64-bit word.
* Handles transitions that exactly fill a 64-bit word.
* Handles transitions crossing a 64-bit boundary.
* Stores completed words as pending data when required.
* Prevents new input when a pending FIFO word cannot be accepted.

### 2. FIFO Buffer

**File:** `rtl/fifo_buffer.v`

The FIFO Buffer stores packed 64-bit words using a circular memory architecture.

Main features:

* 64-bit data width.
* 512 storage locations.
* Independent read and write pointers.
* Extra pointer MSB for full and empty detection.
* Synchronous read operation.
* Write operation when FIFO is not full.
* Read operation when FIFO is not empty.

FIFO status conditions:

```text
Empty:
wr_ptr == rd_ptr

Full:
Lower bits of wr_ptr and rd_ptr are equal
AND
Their MSB values are different
```

### 3. FIFO AXI Wrapper

**File:** `rtl/fifo_axi_wrapper.v`

The FIFO AXI Wrapper transfers data from the 64-bit FIFO interface to the 512-bit AXI interface.

Main functions:

* Reads 64-bit words from the FIFO.
* Collects eight FIFO words.
* Combines eight 64-bit words into one 512-bit AXI data word.
* Generates AXI Write Address transactions.
* Generates AXI Write Data transactions.
* Waits for AXI Write Response.
* Increments the AXI memory address after every successful transfer.

The wrapper uses an FSM to control the transfer operation.

Typical FSM flow:

```text
IDLE
  |
  v
FIFO_READ_REQ
  |
  v
FIFO_READ_CAPTURE
  |
  | (Repeat until 8 FIFO words are collected)
  v
AXI_AW
  |
  v
AXI_W
  |
  v
AXI_B
  |
  v
IDLE
```

### 4. AXI RAM

**File:** `rtl/axi_ram.v`

The AXI RAM module acts as an AXI memory slave.

It receives AXI write transactions generated by the FIFO AXI Wrapper and stores the transferred data in memory.

The AXI RAM provides the memory-side interface for verifying the FIFO-to-AXI data transfer architecture.

### 5. FIFO Top

**File:** `rtl/fifo_top.v`

The top-level module integrates all design blocks.

The data flow is:

```text
Transition Input
      |
      v
Transition Packer
      |
      v
FIFO Buffer
      |
      v
FIFO AXI Wrapper
      |
      v
AXI RAM
```

## Data Flow

### Step 1: Variable-Width Input

The design receives transition data through:

```text
trans_valid
trans_ready
trans_data
trans_width
```

### Step 2: Data Packing

The Transition Packer accumulates incoming transition bits until a complete 64-bit word is formed.

### Step 3: FIFO Storage

Completed 64-bit words are written into the FIFO.

The FIFO provides temporary storage and decouples the transition input from the AXI memory interface.

### Step 4: FIFO Read

The FIFO AXI Wrapper reads data from the FIFO when data is available.

### Step 5: AXI Data Formation

Eight 64-bit FIFO words are collected:

```text
64 bits x 8 = 512 bits
```

These words are combined into one AXI data word.

### Step 6: AXI Memory Write

The wrapper performs the following AXI write sequence:

```text
AW Channel -> Address Transfer
W Channel  -> 512-bit Data Transfer
B Channel  -> Write Response
```

After a successful write response, the AXI address is incremented by 64 bytes.

```text
512 bits = 64 bytes
```

## Key Concepts Demonstrated

* Variable-width data packing
* Bit-level data manipulation
* Circular FIFO implementation
* Full and empty detection using pointer MSBs
* Synchronous FIFO read operation
* Finite State Machine design
* AXI write channel implementation
* Width conversion from 64-bit FIFO data to 512-bit AXI data
* FIFO-to-memory data transfer
